# Documentation

Documentation is maintained with the code.

- `architecture/` — architectural boundaries and responsibilities.
- `development/` — collaboration and development workflow.
- `tranches/` — living tranche tracking.
- `continuity/CURRENT_HANDOFF.md` — single current recovery point between sessions.
- `decisions/` — durable ADR-style decisions when a choice is important enough to justify one.
- `roadmap.md` — planned progression.

Stale documentation is a defect because it creates false context for future sessions.
